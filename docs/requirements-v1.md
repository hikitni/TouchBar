# HTTP Touch Bar 首版需求文档

- 文档版本：v1.0
- 日期：2026-09-07
- 状态：首版开发基线

## 1. 产品目标

在 Mac 上运行一个本地常驻 Agent，通过局域网 HTTP 提供响应式控制网页。手机、平板或桌面浏览器打开该网页后，可作为 Mac 的外置触控副屏，执行常用媒体、音量、亮度、系统和快捷启动操作。

首版以“命令行可运行 MVP”为交付形态，不开发 iOS/Android 原生 App，不要求 BetterTouchTool，也不支持互联网远程控制。

## 2. 用户流程

1. 用户在 Mac 中执行启动命令。
2. Agent 输出局域网访问地址、二维码和六位配对码。
3. 用户使用同一局域网内的浏览器打开地址并输入配对码。
4. 配对成功后，浏览器保存独立设备令牌并进入控制界面。
5. 用户通过标签或滑动手动切换控制页面，点击按钮或拖动音量滑块。
6. Agent 验证设备令牌和动作 ID，在 Mac 本机执行动作，并实时返回成功、失败或不支持状态。

## 3. 首版功能

### 3.1 控制页面

- 横屏优先、纵屏可用的响应式触控布局。
- 支持 `button`、`slider`、`status`、`spacer` 四种组件。
- 页面由版本化 JSON 配置驱动，支持多个 profile。
- profile 通过标签或左右滑动手动切换，并记住最后选中的页面。
- 断线自动重连；断线时禁用控制项并显示连接状态。

### 3.2 动作

首版支持以下服务端动作类型：

- `media`：上一首、播放/暂停、下一首。
- `volume`：静音、设置音量。
- `brightness`：降低或提高内建显示器亮度。
- `system`：锁屏、显示器休眠、截图。
- `launchApp`：按 Bundle ID 启动或切换应用。
- `openUrl`：打开服务端配置的 URL。
- `keystroke`：发送服务端配置的按键组合。
- `bttTrigger`：可选调用 BetterTouchTool Named Trigger；BTT 不存在时显示为不可用。

浏览器只能提交配置中存在的 `actionId` 和经过约束的滑块值，不能提交任意命令、脚本、应用路径或 URL。

### 3.3 状态同步

- HTTP 用于配对、加载配置、查询状态和执行动作。
- WebSocket 用于推送连接状态、状态快照和动作结果；断线重连后重新同步当前配置与能力。
- 首版在 Agent 启动时加载配置并检测本机能力；修改配置或安装/卸载 BTT 后需重启 Agent。
- 音量滑块在浏览器侧节流，在服务端侧串行化，避免系统调用堆积。

### 3.4 配对与安全

- Agent 默认监听 `0.0.0.0:8787`，仅面向可信局域网。
- 启动时生成六位一次性配对码，默认十分钟有效。
- 配对接口限制错误尝试频率；每台设备签发独立随机令牌。
- HTTP API 使用 Bearer Token，不使用 Cookie。
- WebSocket 连接后必须在五秒内发送认证消息。
- 设备令牌持久化到用户数据目录，可由本机 CLI 列出和撤销。
- 不加载第三方脚本，不提供任意 shell 或 AppleScript 执行动作。
- 首版使用 plain HTTP，不承诺抵御同一局域网中的流量监听；互联网访问必须在后续版本增加 HTTPS 或安全隧道。

## 4. 配置模型

配置文件包含：

- `version`：固定为 `1`。
- `server`：端口、配对码有效时间等。
- `profiles[]`：页面 ID、标题、图标、布局和组件。
- `actions`：以 `actionId` 为键的服务端动作定义。

配置无效、ID 重复、动作不存在、滑块越界时必须拒绝启动或拒绝请求，并给出明确错误。

## 5. 非功能要求

- 使用 TypeScript + pnpm workspace。
- 浏览器端使用 React + Vite；Mac Agent 使用 Fastify。
- 支持 Node.js 24 及以上版本，优先支持 Apple Silicon macOS。
- 代码需提供单元测试、API/WebSocket 集成测试和浏览器端组件测试。
- Agent 必须输出结构化、可理解且不包含敏感令牌的日志。
- 缺少辅助功能、自动化或屏幕录制权限时返回明确提示，不得静默失败。

## 6. 首版验收标准

1. 一条命令可以启动 Agent，并输出可访问的局域网地址、二维码和配对码。
2. 同一局域网浏览器可以完成配对并在刷新或 Agent 重启后重新连接。
3. 未配对、令牌错误或令牌已撤销的设备无法执行动作。
4. 默认配置可以执行媒体、音量、亮度、锁屏、显示器休眠、截图、App 启动、URL 和快捷键动作；不支持时必须明确标记。
5. 浏览器无法通过篡改请求执行配置之外的命令或越界参数。
6. 多页面布局可以手动切换并保持最近选择。
7. WebSocket 断线后自动恢复，并同步最新状态。
8. BTT 未安装时，核心能力继续可用，仅 BTT 动作被禁用。
9. `pnpm build`、`pnpm typecheck` 和 `pnpm test` 全部通过。

## 7. 首版不包含

- iOS、iPadOS 或 Android 原生应用。
- 可视化拖拽配置编辑器。
- 自动跟随 Mac 前台应用切换 profile。
- 云账户、跨互联网中继、HTTPS 证书管理。
- 菜单栏 App、开机自启、签名、公证和自动更新。
- 任意 shell、AppleScript 或远程文件操作接口。
